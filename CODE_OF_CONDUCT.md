# Code of Conduct

## Our standard

Contributors and maintainers must keep participation respectful, technically honest, and welcoming.
Good-faith disagreement, evidence-based review, and direct criticism of code are welcome. Harassment,
discrimination, threats, doxxing, sexualized conduct, and publishing another person's private data or
credentials are not acceptable.

## Scope

This standard applies in repository discussions, issues, pull requests, reviews, and other public
spaces where someone represents the project.

## Enforcement

Report conduct concerns through GitHub's repository reporting tools. For security-sensitive reports,
use the private channel described in `SECURITY.md`. Maintainers may edit or remove content, close or
lock threads, reject contributions, or temporarily or permanently restrict participation. Decisions
should be proportionate, documented privately when appropriate, and avoid exposing reporters.
